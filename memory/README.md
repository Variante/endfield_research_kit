# Recovery memory

These six files are the concise sources of truth for current recovery status:

- [`webui_recovery.md`](webui_recovery.md): WebUI build, serving, updates, and
  frontend behavior.
- [`game_story_recovery.md`](game_story_recovery.md): Story coverage,
  ownership, branches, ordering, and remaining gaps.
- [`game_data_recovery.md`](game_data_recovery.md): installed data, formats,
  runtime semantics, and source graph.
- [`asset_recovery.md`](asset_recovery.md): models, materials, media, and
  semantic asset bindings.
- [`animestudio_recovery.md`](animestudio_recovery.md): exporter capabilities,
  diagnostics, and remaining certification work.
- [`character_render_and_animation_recovery.md`](character_render_and_animation_recovery.md):
  character models, rendering, animation, and parity gaps.

Keep conclusions current and short. Put changing inventories and exhaustive
evidence in `reports/`, revisitable experiments in `scratch/`, and disposable
intermediates in `tmp/`. Update an existing topic instead of adding dated
status files.
